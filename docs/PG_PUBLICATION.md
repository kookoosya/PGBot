# Локальная версия и публикация PG

## Локальный запуск

Frontend использует Node.js 22 и зависимости из `frontend/package-lock.json`. Backend использует Python 3.12 и PostgreSQL с UTF-8 и локалью, поддерживающей регистронезависимый поиск по кириллице. База для разработки должна быть отдельной от рабочей базы. Перед запуском API примените миграции из `backend`.

```powershell
# В backend, с настроенными DATABASE_URL и DATABASE_URL_SYNC для локальной базы
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --lifespan off

# В frontend, в другом терминале
$env:PG_API_TARGET = 'http://127.0.0.1:8000'
npm ci
npm run build
npm run preview -- --host 127.0.0.1
```

`--lifespan off` запускает API для локальной приёмки без синхронизации событий, карты, погоды и рассылки. Для разработки интерфейса используйте `npm run dev -- --host 127.0.0.1` вместо сборки и preview. Пустая база показывает состояния без данных. Загружайте опубликованные справочники и другую информацию только после проверки их источников и актуальности.

## Статика, API и фоновые задачи

| Компонент | Что обслуживает | Что нужно при публикации |
| --- | --- | --- |
| Статический frontend | Главная, тарифы, калькулятор, телефон, внешние ссылки, оболочки разделов | CDN или статический origin. `/` отдаёт `dist/index.html`. Вложенные UI-маршруты получают `dist/spa.html` с кодом `200`. Реальные статические файлы и ответы `404` обрабатываются отдельно. |
| FastAPI | Карта и справочники, афиша, объявления, вакансии, каталог и запись к провайдерам, обращения, кабинеты, модерация, помощник, VK callback, страницы `/share/*` | Контейнер или управляемый runtime. Сохраняйте маршрутизацию `/api/*` и `/share/*` на том же публичном origin. Проверяйте заголовки безопасности, сессионные сценарии, лимиты и ограничения размера загрузок. |
| PostgreSQL | Учётные записи, публикации, обращения, места, события, состояния и настройки интеграций | Управляемый PostgreSQL в закрытой сети, миграции и резервные копии с проверкой восстановления. Проверьте `ILIKE` на кириллице. |
| Фоновые задачи | Импорт карты и событий, погода, VK-дайджест | Сейчас задачи запускаются в lifespan процесса FastAPI. При масштабировании или scale-to-zero нужен один управляемый исполнитель или планировщик с отдельными задачами и блокировками от дублей. Текущая внутренняя защита действует в пределах одного процесса. |
| Хранение и интеграции | Вложения, результаты генерации, тайлы OSM и Esri, VK и провайдеры ИИ | Определите persistent storage и политику хранения. Настройте `/tiles/osm/*` и `/tiles/sat/*`, лицензии, атрибуцию, кэш и лимиты. VK и ИИ подключаются отдельно с подтверждёнными настройками и лимитами. |

Сборка получает `PG_PUBLIC_URL` в виде утверждённого HTTPS origin. Для главной сборка выпускает canonical, Open Graph URL, разметку `AutoRepair` и sitemap. `robots.txt` задаёт правила обхода, доступ к закрытым данным контролирует API. При смене домена синхронизируйте `PUBLIC_SITE_URL` на backend и проверьте ссылки шаринга и настройки VK Mini App. Публичные вложенные маршруты рендерятся в браузере. Если понадобится индексировать каждое событие или объявление без JavaScript, им потребуется отдельная серверная выдача.

## Размещение без старого VPS

Для первого этапа подходит управление статикой через CDN, например Cloudflare Pages с отдельными правилами для вложенных маршрутов. Для полного портала понадобится маршрутизация к API. Если для эксплуатации потребуется российский регион, один из вариантов для оценки — Object Storage и CDN для сборки, управляемый контейнер для FastAPI и Managed PostgreSQL в частной сети. Для запуска задач и хранения вложений подберите отдельные ресурсы с подходящим сроком хранения. Проверяйте доступность сайта, DNS и TTFB из целевых сетей до переключения домена. [Правила маршрутизации Cloudflare Pages](https://developers.cloudflare.com/pages/configuration/redirects/)

Оценка бюджета складывается из исходящего трафика и операций CDN и хранилища, времени работы FastAPI и фоновых задач, выделенных ресурсов PostgreSQL, дисков и бэкапов. Для точной суммы нужны трафик, план резервирования и ожидаемый объём данных. Scale-to-zero снижает простой API, но требует отдельного запуска периодических задач и проверки холодного старта. [Object Storage](https://yandex.cloud/ru/docs/storage/pricing), [Cloud CDN](https://yandex.cloud/ru/docs/cdn/pricing), [Serverless Containers](https://yandex.cloud/ru/docs/serverless-containers/pricing), [Managed PostgreSQL](https://yandex.cloud/ru/docs/managed-postgresql/pricing).

Перед открытием регистрации, обращений и публикации контактов определите оператора данных, основание обработки, место хранения, политику и порядок удаления. Это относится также к фотографиям, IP-адресам и данным, уходящим провайдерам ИИ или VK. Для действующих форм нужно проверить информирование и согласие там, где оно является основанием обработки. [152‑ФЗ, статьи 5–10.1, 18–19 и 22](https://www.consultant.ru/document/cons_doc_LAW_61801/).

В репозитории есть исторический workflow `Deploy VPS` с автоматическим триггером на `main`. Перед слиянием ветки владелец должен снять этот триггер или заменить его согласованным процессом публикации. Preview и CI следует запускать на отдельной ветке.
